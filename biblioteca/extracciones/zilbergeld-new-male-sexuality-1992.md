## 3) Reglas cuantitativas y protocolos (para TrainingRule)

### Regla: `pf-kegel-entry-volume`

- **Descripción breve**: iniciar entrenamiento de suelo pélvico con contracciones cortas, dos veces al día.
- **Tipo**: volumen / progresión.
- **Métrica principal**: `repsPerDay`.
- **Valores numéricos**:
  - **Rango inicial**: 15 repeticiones por sesión, 2 sesiones/día.
  - **Progresión objetivo**: aumentar gradualmente hasta ~75 repeticiones por sesión, 2 sesiones/día.
- **Condiciones de aplicación**:
  - Hombres adultos que buscan mejorar sensación pélvica/control eyaculatorio.
  - Sin dolor pélvico; si hay dolor, derivar.
  - No usar como regla de fuerza general.
- **Capítulos/secciones**: Cap. 15, Exercise 15-2.
- **Comentarios/precauciones**:
  - Resultado no inmediato; el libro indica continuar al menos 6 semanas.
  - Evitar tensión de abdomen, muslos o cuello.

## 6) Rehabilitación, prehabilitación y manejo del dolor

### Lesión / condición: Eyaculación rápida / falta de control eyaculatorio

- **Zona**: `pelvic-floor`, genital.
- **Etiología resumida**:
  - Mayormente falta de aprendizaje de señales de arousal, atención y ajustes conductuales.
  - Puede contribuir ansiedad.
  - Raramente físico según el libro.
- **Signos y síntomas clave**:
  - Eyaculación antes de lo deseado.
  - Sensación de no poder controlar.
  - Paso directo de baja excitación a orgasmo sin “zona de control”.
- **Stadia / fases**:
  - Fase educativa: entender control zone y punto de inevitabilidad.
  - Fase individual: masturbación stop-start.
  - Fase con pareja: mano, lubricante, opcional oral.
  - Fase de intercourse: inserción gradual, movimiento, posiciones.
- **Protocolos de tratamiento**:
  - **Fase 1: educación y mente**
    - Objetivo: reducir culpa, visualizar control.
    - Qué se hace: Mind Power A–E, respiración.
    - Qué NO se hace: catastrofizar, pararse en 9/10.
    - Criterio para pasar: usuario puede practicar sin ansiedad alta.
  - **Fase 2: masturbación**
    - Objetivo: reconocer arousal y parar.
    - Qué se hace: 15 min seco/lubricado con paradas.
    - Criterio: 1–2 paradas en 15 min.
  - **Fase 3: pareja**
    - Objetivo: transferir control.
    - Qué se hace: estimulación dirigida con stop/start.
    - Criterio: 15 min con ≤2 paradas y confianza.
  - **Fase 4: intercourse**
    - Objetivo: mantener control con movimiento.
    - Qué se hace: inserción gradual, sin movimiento, movimiento lento, posiciones.
    - Criterio: control suficiente para decidir eyacular.
- **Ejercicios de prehab**:
  - Kegels.
  - Respiración profunda.
  - Foco sensorial.
- **Umbrales de dolor o red flags**:
  - Si coexiste disfunción eréctil, tratar erección primero.
  - Si pérdida súbita de control, evaluar estrés/relación.
  - Medicamentos solo con médico.
- **Referencias**: Cap. 20.

---

### Lesión / condición: Problemas de erección

- **Zona**: `penis`, sistema vascular/neurológico/hormonal.
- **Etiología resumida**:
  - Orgánica: vascular, neurológica, diabetes, hormonal, medicamentos.
  - Psicológica: ansiedad, estrés, conflicto, baja excitación, condiciones no cumplidas.
  - Mixta: frecuente.
- **Signos y síntomas clave**:
  - Dificultad para obtener erección.
  - Dificultad para mantenerla.
  - Erección menos rígida.
  - Erecciones situacionales vs ausentes en todos los contextos.
- **Evaluación sugerida por el libro**:
  - ¿Hay erecciones nocturnas/masturbación?
  - ¿Ocurre solo con pareja?
  - ¿Hay deseo bajo?
  - ¿Medicamentos, alcohol, tabaco?
  - ¿Enfermedades cardiovasculares, diabetes, trauma pélvico?
- **Protocolos**:
  - **Fase 1: triaje médico**
    - Objetivo: descartar causa orgánica.
    - Si no hay erección en ningún contexto: derivar urología/médico.
    - Si deseo bajo: evaluar testosterona, depresión, medicamentos.
  - **Fase 2: reducción de ansiedad**
    - Objetivo: quitar presión de intercourse.
    - Qué se hace: prohibir intercourse temporalmente, foco en placer/arousal.
    - Criterio: menor ansiedad, mayor comodidad.
  - **Fase 3: ejercicios individuales**
    - Placer con pene suave.
    - Perder/recuperar erección.
  - **Fase 4: ejercicios con pareja**
    - Estimulación sin demanda.
    - Perder/recuperar con pareja.
    - Inserción gradual.
    - Movimiento gradual.
- **Ejercicios de prehab**:
  - Condiciones: descanso, sobriedad, privacidad, conexión.
  - Foco sensorial.
  - Respiración.
  - Autoinstrucciones positivas.
- **Red flags**:
  - Sin erecciones en ningún contexto.
  - Dolor, curvatura marcada, trauma.
  - Síntomas cardiovasculares.
  - Uso de nitratos con sildenafil.
  - Priapismo con inyecciones: erección prolongada requiere atención médica.
- **Referencias**: Caps. 21, 22.

### Lesión / condición: Bajo deseo o discrepancia de frecuencia

- **Zona**: sistémica/relacional.
- **Etiología resumida**:
  - Diferencias naturales de preferencia.
  - Hormonas bajas.
  - Depresión.
  - Medicamentos.
  - Estrés laboral/financiero.
  - Insatisfacción sexual.
  - Conflicto relacional.
  - Miedo a intimidad.
  - Trauma sexual.
- **Signos y síntomas clave**:
  - Falta de pensamientos/fantasías sexuales.
  - Falta de iniciativa.
  - Rechazo frecuente.
  - Deseo presente pero no voluntad de actuar.
- **Protocolo**:
  - **Fase 1: mejorar relación**
    - Reducir culpa y acusaciones.
    - Empatía mutua.
  - **Fase 2: conversación estructurada**
    - Cada persona habla; otra escucha y resume.
  - **Fase 3: definir objetivo concreto**
    - ¿Qué se quiere más? ¿afecto, contacto, intercourse, orgasmo, cercanía?
  - **Fase 4: detectar cambio temporal**
    - Si hubo cambio, identificar evento disparador.
  - **Fase 5: evaluación médica**
    - Hormonas, depresión, medicamentos, enfermedad.
  - **Fase 6: negociar cambios**
    - Alternativas no coitales, agendas, condiciones, terapia.
- **Red flags**:
  - Coerción o culpa.
  - Depresión.
  - Trauma/abuso.
  - Dolor.
- **Referencias**: Cap. 24.

## 7) Factores de estilo de vida (sueño, estrés, nutrición, entrenar enfermo)

### Sueño / descanso

- **Qué dice el libro**: estar cansado reduce deseo, excitación y función sexual; descansar es una condición importante.
- **Horas recomendadas**: ⚠️ no se especifican.
- **Regla cualitativa**:
  - Si el usuario está fatigado, no forzar actividad íntima ni ejercicios sexuales.
  - Priorizar descanso como condición de readiness.
- **Referencias**: Cap. 6; Cap. 18.

### Estrés

- **Qué dice el libro**: estrés laboral, preocupación, conflicto de pareja y ansiedad de desempeño reducen arousal y erección.
- **Estrategias**:
  - Actividad de transición antes de intimidad: ejercicio suave, baño, lectura, juego.
  - Time-out de 30–90 minutos en conflicto.
  - Respiración profunda.
  - Reestructuración cognitiva.
- **Regla potencial**:
  - Si estrés alto, reducir exigencia y priorizar regulación antes de actividad sexual o tareas de pareja.
- **Referencias**: Caps. 6, 13, 15, 19.

### Nutrición

- **Qué dice el libro**: no hay protocolo nutricional.
- **Elementos relevantes**:
  - Alcohol: pequeñas cantidades pueden relajar, pero exceso deteriora erección.
  - Alcoholismo crónico puede afectar testosterón y función sexual.
  - No se habla de calorías, proteínas o suplementación deportiva.
- **Nota**: ⚠️ no usar para reglas de nutrición deportiva.
- **Referencias**: Cap. 21; Apéndice.

### Sustancias

- **Alcohol**: exceso → problemas de erección; alcoholismo → efectos hormonales/sexuales.
- **Tabaco**: contribuye a endurecimiento/obstrucción arterial; mayor riesgo de problemas de erección.
- **Drogas recreativas**: pueden tener efectos mixtos; uso prolongado/dosis altas causan disfunción; riesgo de dependencia.
- **Medicamentos**: muchos pueden causar efectos sexuales adversos; no suspender sin médico.
- **Referencias**: Cap. 21; Apéndice.

### Entrenar enfermo

- **Qué dice el libro**: no hay reglas tipo “above/below the neck”.
- **Regla cualitativa**:
  - Enfermedad aguda puede reducir deseo; no forzar actividad sexual.
  - Si hay enfermedad crónica, evaluar médico.
- **Nota**: ⚠️ no es fuente de reglas para entrenamiento con fiebre/resfriado.

La clave es que **no debe tratarse como una `TrainingRule` normal**, sino como una regla de interacción farmacológica / bandera roja médica. Debe:

1. **Detectar simultaneidad o posible coadministración** de:

3. **Mostrar una advertencia dura** y derivar a médico.

4. **No permitir override automático** por parte del motor de reglas.

## 4) Lógica de evaluación para el motor de reglas

Pseudocódigo recomendado:

```ts
function evaluateMedicationInteractionRules(
  userMedications: MedicationClassId[],
  rules: MedicationInteractionRule[]
): MedicationInteractionRule[] {
  return rules.filter(rule => {
    const hasPrimary = userMedications.some(med =>
      rule.trigger.anyUserMedicationClass.includes(med)
    );

    const hasInteracting = userMedications.some(med =>
      rule.trigger.andAnyCoAdministeredClass.includes(med)
    );

    return hasPrimary && hasInteracting;
  });
}
```

Ejemplo de evaluación:

```ts
const userMeds: MedicationClassId[] = ['PDE5_INHIBITOR', 'NITRATE'];

const activeCriticalRules = evaluateMedicationInteractionRules(
  userMeds,
  medicationInteractionRules
);
```

Resultado esperado:

```ts
activeCriticalRules.some(
  rule => rule.id === 'redflag_pde5_nitrate_contraindication'
);
// true
```

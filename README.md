# Alexander Woodcock Salomon Portfolio

Public portfolio website for international remote employability, centered on TwinSight X500 and the Human / CG Cookie Blender character pipeline study.

## Development

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

## Content Model

Project copy, routes, placeholders, links, and focus variants are stored in `src/data`.

Unset public links intentionally remain as bracketed placeholders such as `[GITHUB_URL]`, `[DEMO_VIDEO_URL]`, `[CV_PDF_URL]`, and `[EMAIL]` until final assets are ready.

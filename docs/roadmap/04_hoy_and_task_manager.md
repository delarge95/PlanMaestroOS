# Hoy y Task Manager

## Objetivo
Pantalla Hoy como centro de control diario, con foco y baja carga cognitiva.

## Estructura
- Encabezado mínimo.
- Top 3.
- Bloques A/B.
- Filas condensadas por área.
- Calendario y canvas.
- Tablas visuales opcionales.

## Reglas UX
- Máximo 3 tareas en foco.
- Acciones claras y reversibles.
- Mensajes de apoyo, no de exigencia.

## Integración con Notion
- Lectura de tareas del día.
- Escritura de cambios de estado.

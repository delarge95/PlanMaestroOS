# Pipeline de contenido “Ver más tarde”

## Objetivo
Capturar, organizar y procesar contenido guardado de FB, IG y YT.

## Fuentes
- Facebook.
- Instagram.
- YouTube.

## Proceso
- Captura de enlaces.
- Clasificación por categoría.
- Extracción de metadatos.
- Guardado en Notion/local.

## Categorías
- Fitness.
- Gastronomía.
- Carrera.
- Idiomas.
- IA / 3D / Tech.

## Reglas UX
- No mostrar todo a la vez.
- Usar “ver más tarde” como cola, no como feed infinito.

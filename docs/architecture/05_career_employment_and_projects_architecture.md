# 05 · Laboral: carrera, empleo y proyectos

## Objetivo
Crear una sección Laboral robusta que combine roadmap, portafolio, proyectos, empleo, cursos y noticias, manteniendo el foco en próximos pasos y claridad.

## 1. Roadmap, Portafolio y CV
- Roadmap con:
  - goals corto/mediano/largo plazo,
  - vista calendario,
  - posibilidad de re-priorizar.
- Portafolio y CV:
  - versiones por rol (Tech Artist, QA, etc.),
  - enlaces a GitHub, LinkedIn, ArtStation, web,
  - selección de proyectos para destacar.

### Futuro agente IA
- Analizar ofertas y mercado.
- Proponer mejoras de SEO y contenido.
- Sugerir ajustes de CV por rol.

## 2. Proyectos
- Subsecciones por proyecto activo (ej. TwinSight, Human).
- Cada uno muestra:
  - tareas pendientes,
  - estado en GitHub (issues, PRs),
  - decisiones importantes.
- Base de datos de proyectos completados:
  - estado (pulir, mejorar, listo para portfolio).

## 3. Empleo
### Pipeline
- Frío, tibio, caliente.
- Cada entrada:
  - empresa,
  - rol,
  - contacto,
  - estado,
  - próxima acción,
  - CV/mensajes enviados.

### Cronograma
- Hoy, Mañana, Pasado mañana, Próximos días.
- Listas de empresas a contactar y acciones concretas.

### Base de datos histórica
- Registro completo de:
  - mensajes,
  - CVs,
  - respuestas,
  - entrevistas.

### Investigación
- Tendencias, ofertas relevantes, nuevas empresas.

## 4. Cursos y aprendizaje
- Hoy: tareas de cursos activos.
- Cursos activos.
- Cursos en la mira con prioridad.
- Noticias sobre cursos, másteres, becas.

## 5. Noticias y contenido
Categorías propuestas:
- IA: tendencias y conocimiento profundo.
- 3D / Tech Art: teoría y práctica.
- Desarrollo y diseño.
- Carrera y empleabilidad.

La sección de noticias alimenta “ver más tarde” con filtros por categoría.

# E1 — Technical Volunteering Opportunities

## 1. Executive summary

This module maps technical volunteering routes that can produce credible experience for Alexander without requiring a formal job offer.

The strongest opportunities are not generic volunteering roles. They are technical contribution paths where Alexander can produce visible artifacts:

- public repositories;
- data visualizations;
- GIS or map outputs;
- XR accessibility resources;
- small Unity/WebGL demos;
- documentation;
- workflow automation;
- humanitarian mapping contributions;
- civic-tech prototypes.

The highest ROI paths for Alexander are:

1. Humanitarian mapping / geospatial visualization.
2. XR accessibility / inclusive immersive design.
3. Games and immersive media for social impact.
4. AI/data support for nonprofits.
5. Open engineering / CAD / digital-twin adjacent communities.
6. Civic-tech prototyping.

These can support future applications to roles in Unity WebGL, technical visualization, XR, simulation, digital twins and tools/pipeline.

## 12. Final recommendation

Alexander should prioritize **one geospatial/digital-twin path** and **one XR/accessibility path**.

Recommended sequence:

```text
1. HOT OSM / Missing Maps
2. OpenDroneMap
3. XR Access
4. Games for Change
5. DataKind or Tech To The Rescue
```

This sequence produces a coherent story:

```text
I build browser-based 3D technical visualization systems for real-world spatial, educational and humanitarian use cases.
```

That story is stronger than generic volunteering and more aligned with Unity WebGL, technical art, simulation and digital twins.

## 6.3 CV summary core

```text
Real-Time 3D Developer / Unity Technical Artist focused on Unity WebGL, C#, CAD-to-realtime optimization and interactive technical visualization. Built TwinSight X500, a browser-based drone assembly inspection prototype with component selection, exploded view, cross-section tools, visual modes, technical UI and SUS/NASA-TLX evaluation.
```

## 6.4 TwinSight CV bullet set

Use 3–5 bullets depending on role.

### Default bullets

```text
- Built TwinSight X500, a Unity WebGL technical visualization prototype for drone assembly inspection using Unity, C#, URP, UI Toolkit and Blender.
- Implemented component selection, exploded view, cross-section/clipping tools, visual modes and technical information panels for interactive 3D inspection.
- Optimized CAD-derived source routes exceeding 6.5M triangles into a 95,617-triangle WebGL-ready model while preserving component-level readability.
- Evaluated the prototype with 12 participants using SUS, NASA-TLX Raw and Think-Aloud protocols, collecting 96 task-condition records.
- Documented technical constraints, usability findings and future improvements for digital-twin-adjacent technical visualization workflows.
```

### Technical Artist variant

```text
- Developed visual inspection modes including realistic, X-ray, ghosted, blueprint, wireframe, solid and thermal-style qualitative views.
- Focused on rendering constraints, WebGL performance, visual readability and technical-art presentation for interactive inspection.
```

### Unity WebGL variant

```text
- Deployed the prototype as a browser-based Unity WebGL viewer, emphasizing no-install access, runtime interaction and optimized 3D assets.
```

### Technical Visualization variant

```text
- Designed the viewer to reduce spatial reasoning friction in drone assembly understanding compared with static 2D support.
```

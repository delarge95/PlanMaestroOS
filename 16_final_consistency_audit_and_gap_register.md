## Safe public claims

These can be used in CV, LinkedIn, GitHub, portfolio, and interviews if factually true:

- Unity WebGL technical visualization prototype.
- Real-time 3D drone assembly inspection.
- CAD-to-realtime asset optimization.
- C# runtime interaction systems.

- Exploded view and cross-section/clipping.

- Thesis completed, pending defense.
- Academic usability evaluation if final data is confirmed.
- AI-assisted implementation under human technical ownership.

## Conditional claims

Use only if confirmed:

| Claim | Condition |
|---|---|
| Triangle reduction from 6.5M+ to 95,617 | Verify exact source and final number |
| SUS 91.88 | Verify final report |
| NASA-TLX 8.69 vs 19.89 | Verify final report |

| Live WebGL demo | Confirm public URL |
| Public GitHub code | Confirm repo state |
| ARA almost functional | Confirm reproducible run |
| Blender portrait complete | Confirm final renders/breakdown |
| English C1 | Use as self-assessed unless certified |
| Portuguese passport in ~2 years | Phrase as expected, not guaranteed |

## Claims to avoid

Do not claim:

- “Senior Technical Artist.”
- “EU work authorization” before passport/residence exists.
- “German work authorization” before residence title exists.
- “Certified Unity Developer” unless certified.
- “Certified Rebelway / CG Cookie” if no certificate exists.
- “Production AI engineer.”
- “Enterprise-ready AI platform.”
- “Commercially shipped Unity product” unless true.
- “All code written manually” if AI assistance was used.
- “AI built the project” because it undermines technical ownership.
- “Full-stack specialist” as main positioning.

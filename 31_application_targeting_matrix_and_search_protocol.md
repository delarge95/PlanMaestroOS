# 8. Remote eligibility protocol

Do not treat “remote” as enough.

Every posting must be labeled as one of:

```text
Worldwide
LATAM only
US only
Canada only
EU only
EU + NA
UK only
Hybrid
On-site
Unknown
```

## 8.1 Colombia suitability labels

| Label | Meaning |
|---|---|
| Colombia-eligible | explicitly LATAM/global/contractor |
| Likely eligible | no restriction visible, but remote/global wording |
| Unclear | remote but region not defined |
| Likely not eligible | EU/NA/US-only |
| Not eligible | work authorization excludes Colombia |

## 8.2 Immediate filter

Reject or postpone if:

```text
US work authorization required
EU work authorization required now
hybrid in city/country not accessible
security clearance required
onsite only
```

Exception:

```text
Save for future EU/Portugal/Germany path if strategically relevant.
```

# 9. Application scoring model

Score each opportunity from 1 to 5.

## 9.1 Fit score

| Score | Definition |
|---:|---|
| 5 | Direct TwinSight fit: Unity/WebGL/technical visualization/CAD/interactive 3D |
| 4 | Strong Unity/technical art/XR fit with one gap |
| 3 | General Unity role with partial overlap |
| 2 | Weak role with mostly unrelated requirements |
| 1 | Distraction |

## 9.2 Probability score

| Score | Definition |
|---:|---|
| 5 | remote LATAM/contractor + portfolio-based + not senior-heavy |
| 4 | plausible with strong project proof |
| 3 | competitive but possible |
| 2 | mostly senior/shipped-title/local-only |
| 1 | unrealistic now |

## 9.3 Compensation score

| Score | Definition |
|---:|---|
| 5 | likely USD 6k+/month path |
| 4 | likely USD 3k–6k/month |
| 3 | likely USD 1.5k–3k/month |
| 2 | low/unclear |
| 1 | below target or unpaid |

## 9.4 Portfolio-fit score

| Score | Definition |
|---:|---|
| 5 | TwinSight directly answers role requirements |
| 4 | TwinSight + ARA/portrait answer most requirements |
| 3 | needs portfolio adaptation |
| 2 | current proof weak |
| 1 | unrelated portfolio |

## 9.5 Region score

| Score | Definition |
|---:|---|
| 5 | LATAM remote / Colombia eligible |
| 4 | global remote |
| 3 | unclear but possible |
| 2 | EU/NA-only but maybe future |
| 1 | not eligible |

## 9.6 Total score

```text
Total = Fit + Probability + Compensation + Portfolio-fit + Region
Max = 25
```

## 9.7 Action threshold

| Total | Action |
|---:|---|
| 21–25 | Apply now with tailored materials |
| 17–20 | Apply if materials are close |
| 13–16 | Save / apply only if low effort |
| 9–12 | Watchlist |
| ≤8 | Reject |

# 24. Decision tree

## 24.1 Should Alexander apply?

```text
Is it remote or Colombia/LATAM eligible?
    No → reject or future watchlist.
    Yes → continue.

Does it require senior shipped-title experience?
    Yes → only apply if fit ≥ 5 and portfolio match ≥ 4.
    No → continue.

Does TwinSight directly support the role?
    Yes → score high.
    No → continue.

Can CV + portfolio be tailored in under 30 minutes?
```

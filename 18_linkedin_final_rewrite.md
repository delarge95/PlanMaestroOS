# 18_linkedin_final_rewrite

## Purpose

This document converts the approved career strategy and CV positioning into a complete LinkedIn profile rewrite.

It includes:

- final headline recommendation;
- 15 headline alternatives;
- About section;
- Experience rewrite;
- Education rewrite;
- Projects section;
- Featured section order;
- Skills ordering;
- Creator/activity strategy;
- recruiter keyword strategy;
- availability and work-authorization wording;
- future EU/Portugal/Germany wording;
- sections to avoid or downplay.

This document is written in English because the target market is international remote work.

---

# 1. LinkedIn positioning rule

The LinkedIn profile must communicate one coherent identity:

```text
Real-Time 3D Developer / Unity Technical Artist focused on interactive technical visualization, CAD-to-realtime optimization, and Unity WebGL deployment.
```

It must not present separate unrelated identities such as:

```text
Full-stack developer + AI engineer + 3D artist + game developer + researcher + designer
```

Those areas can exist as supporting evidence, but not as equal headline identities.

---

# 2. Final recommended headline

Use this as the primary headline:

```text
Real-Time 3D Developer / Unity Technical Artist | Unity WebGL, C#, CAD-to-Realtime Optimization, Technical Visualization
```

## Why this headline works

It balances:

- role identity;
- engine/tool keywords;
- technical visualization niche;
- recruiter-search keywords;
- portfolio alignment with TwinSight X500;
- enough specificity without overclaiming seniority.

It avoids:

- “Senior”;
- “AI Engineer” as primary identity;
- “Full-stack” as primary identity;
- vague “multimedia engineer” wording;
- generic “3D artist” positioning.

```text
One of the main challenges in TwinSight X500 was converting CAD-derived drone geometry into assets suitable for real-time WebGL inspection.

The goal was not to preserve every raw CAD detail. The goal was to preserve component identity, assembly relationships and inspection clarity while reducing geometry enough for browser deployment.

That required:
- cleanup;
- retopology decisions;
- UV preparation;
- asset grouping;
- real-time material planning;
- Unity integration;
```

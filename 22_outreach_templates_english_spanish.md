# 22_outreach_templates_english_spanish

## Purpose

This document provides reusable outreach templates for the international job-search system.

It includes English and Spanish versions for:

- recruiter connection messages;
- hiring manager messages;
- technical art lead messages;
- Unity technical director messages;
- XR / simulation / digital twin companies;
- creative technology studios;
- game studio recruiters;
- speculative applications;
- referral requests;
- professor / advisor recommendation requests;
- former freelance client testimonial requests;
- follow-ups;
- salary expectation responses;
- remote-from-Colombia explanations;
- contractor setup explanations;
- future Portuguese / EU mobility explanations;
- contract/payment questions;
- declining unstable offers;
- explaining low formal experience;
- explaining AI-assisted development;
- answering “Why should we hire you?”

The goal is to support consistent, direct, non-desperate, evidence-based communication.

---

# 1. Messaging principles

## Core positioning

Every message should reinforce this identity:

```text
Real-Time 3D Developer / Unity Technical Artist focused on interactive technical visualization, CAD-to-realtime optimization, and Unity WebGL deployment.
```

## Primary proof

Use TwinSight X500 as the main proof asset.

```text
TwinSight X500 = Unity WebGL technical visualization prototype for drone assembly inspection.
```

## Secondary proof

Use ARA only when relevant:

```text
ARA Framework = Python/LangGraph research automation prototype.
```

## Tone

Use:

- direct;
- technically specific;
- concise;
- evidence-based;
- no begging;
- no exaggerated enthusiasm;
- no inflated seniority.

Avoid:

- “I am passionate about everything tech”;
- “I would love any opportunity”;
- “I can do anything”;
- long autobiographical explanations;
- overexplaining legal status;
- overexplaining AI usage unless asked.

## Minimum personalization per message

Every message should include at least:

1. company name;
2. relevant role or product;
3. why TwinSight is related;
4. portfolio or GitHub link.

## English

```text
Before moving forward, I’d like to clarify a few contract details:

1. Is the role employee, contractor, B2B, or EOR-based?
2. What is the expected weekly availability?
3. What time-zone overlap is required?
4. What is the payment currency and method?
5. What are the payment terms?
6. Are there paid time off, holidays or sick-day provisions?
7. How is IP ownership handled?
8. Are there exclusivity or non-compete clauses?
9. What equipment or software is provided?
10. What is the termination notice period?
```

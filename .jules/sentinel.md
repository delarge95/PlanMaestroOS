## 2025-05-18 - Safe Embed URL Validation & Restricted Iframe Sandboxing
**Vulnerability:** Dynamic iframe-rendering components (`SecondBrainInspector`, `YouTubePlayer`, `ThenxGuideDatabase`) accepted third-party URLs without protocol or domain validation, rendering untrusted iframes without restrictive `sandbox` attributes. This posed risks of DOM XSS, open redirects, phishing via embedded sites, and clickjacking/unrestricted script execution.
**Learning:** React components rendering iframes based on dynamic input or stored state must strictly validate scheme (HTTPS only) and match hostnames against a domain whitelist (e.g. YouTube, Vimeo, Notion). Moreover, explicit `sandbox` attributes (e.g. `sandbox="allow-scripts allow-same-origin allow-presentation"`) must be defined to enforce defense-in-depth across dynamic iframe views.
**Prevention:** Always sanitize third-party dynamic URLs using `isValidEmbedUrl` prior to setting iframe `src`, restrict hostnames against an allowed domain whitelist, and apply restrictive `sandbox` permissions on all `<iframe>` elements.

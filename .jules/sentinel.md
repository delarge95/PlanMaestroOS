## 2025-03-30 - Dynamic Embed URL Whitelisting & Iframe Sandboxing
**Vulnerability:** Interactive components (`SecondBrainInspector`, `YouTubePlayer`, `ThenxGuideDatabase`) rendered third-party user-controlled or dynamically formatted iframe embed URLs (`src`) without URL scheme or domain validation, allowing potential XSS, open redirection, or arbitrary content injection if bad URLs were provided.
**Learning:** Rendering dynamic URLs in `<iframe>` elements without protocol enforcement (HTTPS) and domain whitelist validation exposes the frontend to clickjacking or untrusted external script execution. Furthermore, un-sandboxed `<iframe>` elements possess full access to top-level navigation and script contexts.
**Prevention:** Always validate third-party dynamic iframe URLs using `isValidEmbedUrl` to ensure `https:` scheme and strict whitelist matching against allowed domains (e.g., notion.so, notion.site, notion.com, v1.embednotion.com, youtube.com, youtu.be, vimeo.com, player.vimeo.com), and apply restrictive `sandbox` attributes (`sandbox="allow-scripts allow-same-origin allow-presentation allow-popups"`) to all iframe embeds.

## 2026-08-06 - Dynamic Iframe URL Injection & Clickjacking Prevention
**Vulnerability:** User-controlled dynamic input URLs were saved directly in local storage and rendered inside iframes without domain or protocol validation. This exposed the application to Potential open redirect, phishing, clickjacking, and XSS (cross-site scripting) attacks inside trusted UI boundaries.
**Learning:** Client-side components that leverage configuration-driven iframes (like Notion Workspace integration and YouTube video embeds) often assume the configured URLs are trusted. Without strict whitelist validation and robust `sandbox` attributes, bad actors can hijack the embedded frame context.
**Prevention:** All dynamic embeds must use a central URL validator verifying exactly HTTPS protocol and strict domain whitelists (e.g., `notion.so`, `youtube.com`). In addition, the `iframe` elements must strictly employ a minimal `sandbox` attribute configuration (e.g., `allow-scripts allow-same-origin`) to restrict unauthorized browser API access and navigation.

\chapter{Playbook semana por semana}

\section{Como usar este playbook}


Esta es la parte mas prescriptiva del documento. Si un dia no sabes que hacer, usa la fila correspondiente. Si una tarea ya esta hecha, no inventes una nueva rama: adelanta la siguiente fila de la misma semana o mejora el entregable de esa fase.


\subsection{Reglas}


\begin{itemize}
\item Cada semana tiene un entregable visible.
\item Cada miercoles mantiene la busqueda viva.
\item Cada jueves estudia solo lo que desbloquea output.
\item Cada viernes decide con datos, no con animo.
\item Semana 16 no es final definitivo; es puerta de decision.
\end{itemize}

\subsection{Minimo viable por semana}


Si una semana se complica, el minimo es:


\begin{enumerate}
\item 1 entregable publico o mejora visible.
\item 3 aplicaciones o follow-ups.
\item Tracker actualizado.
\item 1 decision escrita para la semana siguiente.
\end{enumerate}

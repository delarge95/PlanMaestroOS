\chapter{Pivotes, riesgos y recuperacion}

\section{Pivotes}


Un pivote solo se hace por evidencia, no por una mala semana.


\subsection{Si no hay respuestas tras 20 aplicaciones}


\begin{enumerate}
\item Revisar fit score: aplicaste a roles correctos?
\item Revisar primer viewport del portfolio.
\item Revisar CV headline y bullets.
\item Revisar si GitHub abre bien.
\item Enviar 5 mensajes de feedback a contactos/recruiters.
\item Ajustar target, no cambiar identidad completa.
\end{enumerate}


\subsection{Si hay respuestas pero no entrevistas}


\begin{itemize}
\item El problema probable es CV/fit o links.
\item Mejorar CV y portfolio landing.
\item Adaptar mas los bullets al posting.
\item Usar TwinSight como prueba directa en el primer mensaje.
\end{itemize}


\subsection{Si hay entrevistas pero no ofertas}


\begin{itemize}
\item El problema probable es defensa tecnica, salario o seniority.
\item Practicar walkthrough de TwinSight.
\item Preparar respuestas a digital twin, AI, WebGL, optimization.
\item Usar scorecard para no sonar desesperado.
\end{itemize}

\chapter{Playbooks por tipo de rol}

\section{Unity Technical Artist}


Este es el rol principal. La narrativa debe centrarse en pipeline, optimization, realtime constraints, visual clarity, Unity/Blender bridge and technical communication.


Usar:


\begin{itemize}
\item TwinSight pipeline CAD-to-realtime.
\item Optimization before/after.
\item Clipping, exploded view and visual modes.
\item Human CGCookie as visual support.
\item ArtStation breakdown.
\end{itemize}


Evitar:


\begin{itemize}
\item Venderte como AAA senior.
\item Hablar solo de gameplay.
\item Mostrar solo codigo sin visual pipeline.
\end{itemize}


CV angle:


\begin{mdcode}
Bloque de codigo: text
Unity Technical Artist focused on realtime 3D visualization, asset optimization and Unity/Blender pipelines for interactive technical experiences.
\end{mdcode}


\section{Unity WebGL Developer}


Este rol es muy aplicable si la vacante pide Unity builds, C\#, browser deployment, interaccion o tooling.


Usar:


\begin{itemize}
\item TwinSight running in WebGL/browser.
\item C\# interaction systems.
\item UI Toolkit and technical interface.
\item Performance constraints.
\end{itemize}


Evitar:


\begin{itemize}
\item Presentar Human como proyecto principal.
\item Sobreenfocar Houdini o VFX.
\end{itemize}


CV angle:


\begin{mdcode}
Bloque de codigo: text
Unity WebGL Developer with experience building browser-based interactive 3D inspection prototypes using Unity, C#, UI Toolkit and optimized 3D assets.
\end{mdcode}


\section{Technical Visualization / Product Visualization}


Este rol puede pagar bien y alinea muy fuerte con TwinSight.


Usar:


\begin{itemize}
\item Assembly inspection problem.
\item Technical documentation to interactive 3D.
\item Metrics and evaluation.
\item CAD-to-realtime workflow.
\end{itemize}


Evitar:


\begin{itemize}
\item Venderlo como producto industrial terminado.
\item Decir digital twin sin matiz.
\end{itemize}


CV angle:


\begin{mdcode}
Bloque de codigo: text
Technical visualization developer focused on transforming complex 3D/technical documentation into interactive realtime inspection workflows.
\end{mdcode}


\section{XR / Simulation}


Usar como ruta secundaria si la empresa trabaja training, inspection, industrial simulation or immersive visualization.


Usar:


\begin{itemize}
\item Interaction design.
\item Inspection workflow.
\item Unity realtime scene structure.
\item Productionization roadmap toward XR.
\end{itemize}


Evitar:


\begin{itemize}
\item Prometer experiencia XR profunda si no existe.
\item Comprar hardware o abrir proyecto nuevo antes de aplicar.
\end{itemize}


\section{Python / AI Tooling}


Ruta secundaria. Solo activar con ARA funcional o rol mixto.


Usar:


\begin{itemize}
\item ARA as research automation prototype.
\item Structured workflows.
\item Markdown/report generation.
\item Human-in-the-loop ownership.
\end{itemize}


Evitar:


\begin{itemize}
\item Production AI Engineer como identidad.
\item Autonomous AI claims.
\item Desplazar TwinSight.
\end{itemize}


\section{3D / Blender fallback}


Usar si la oportunidad da experiencia visual/technical art real.


Usar:


\begin{itemize}
\item Human renders.
\item TwinSight visual breakdown.
\item Optimization and presentation.
\end{itemize}


Evitar:


\begin{itemize}
\item Aceptar rol puramente artistico sin ruta TA si no es necesario.
\item Entrar en competencia de artistas senior sin diferenciador tecnico.
\end{itemize}

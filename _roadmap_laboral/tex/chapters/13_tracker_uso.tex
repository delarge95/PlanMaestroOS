\chapter{Como usar el tracker}

\section{Funcion del tracker}


El tracker no es archivo administrativo. Es el mecanismo para que la estrategia no dependa de memoria o ansiedad.

\subsection{Rutina semanal}


\begin{enumerate}
\item Lunes: actualizar Weekly Plan y elegir foco.
\item Miercoles: registrar aplicaciones y outreach.
\item Jueves: registrar estudio/output.
\item Viernes: actualizar estados, follow-ups y metricas.
\end{enumerate}

\subsection{Regla de revision}


Si el tracker no muestra movimiento en 2 semanas, el problema no es motivacion: es que el sistema esta demasiado pesado o el foco esta mal definido. Reducir entregables, no abandonar estrategia.

\section{Objetivo del portfolio}


El portfolio debe responder cinco preguntas sin que el usuario piense demasiado:


\begin{enumerate}
\item Que haces?
\item Cual es tu mejor prueba?
\item Que parte hiciste tu?
\item Que tecnologias usaste?
\item Como te contacto o reviso mas?
\end{enumerate}

\subsection{Copy base para TwinSight}


\begin{mdcode}
Bloque de codigo: text
TwinSight X500 is a Unity WebGL technical visualization prototype for drone assembly inspection. It transforms static technical documentation into an interactive browser-based 3D viewer with component selection, exploded view, clipping/cross-section tools, visual modes and contextual information panels.

The project demonstrates CAD-to-realtime optimization, Unity interaction design, WebGL constraints, UI implementation and usability/workload evaluation. It is an academic/portfolio prototype, not a production digital twin with live telemetry.
\end{mdcode}

\subsection{Definition of done portfolio}


\begin{itemize}
\item El homepage dice Unity Technical Artist / Real-Time 3D.
\item TwinSight se puede abrir desde el primer viewport.
\item Hay al menos un video o GIF funcional.
\item Los links a GitHub/LinkedIn/CV funcionan.
\item Las limitaciones estan explicadas sin bajar el valor.
\item No hay placeholders visibles.
\end{itemize}

\section{Semana tipo}


La semana se disena para evitar dos trampas: trabajar solo en portfolio y nunca aplicar, o aplicar sin evidencia suficiente. La estructura balanceada es fija, pero el contenido cambia por fase.

\subsection{Lunes}


\begin{enumerate}
\item Abrir tracker y revisar Dashboard.
\item Elegir foco semanal: portfolio, public profiles, applications o interview.
\item Definir 3 entregables maximo.
\item Bloquear 2 horas para el activo mas importante.
\item Cerrar el dia con una version visible, no solo notas.
\end{enumerate}


\subsection{Martes}


\begin{enumerate}
\item Trabajar en el canal publico mas debil.
\item Si portfolio no esta listo, portfolio manda.
\item Si portfolio esta listo, GitHub o CV manda.
\item Si GitHub/CV estan listos, LinkedIn/ArtStation manda.
\item Publicar o preparar para publicar; no dejarlo todo en borrador.
\end{enumerate}


\subsection{Miercoles}


\begin{enumerate}
\item Recolectar 10-15 roles/empresas.
\item Scorear cada uno en el tracker.
\item Descartar sin culpa los que fallen por authorization, onsite o marketing puro.
\item Aplicar a 3-6 roles con fit alto.
\item Enviar 2-4 mensajes de outreach si hay contacto razonable.
\end{enumerate}


\subsection{Jueves}


\begin{enumerate}
\item Estudiar solo un bloqueo real.
\item Convertir el estudio en mejora visible: screenshot, README, video, commit o answer bank.
\item Practicar una pregunta tecnica.
\item Actualizar tracker de estudio.
\item No iniciar curso nuevo si no se cerro el output anterior.
\end{enumerate}


\subsection{Viernes}


\begin{enumerate}
\item Actualizar estados de aplicaciones.
\item Enviar follow-ups pendientes.
\item Revisar si hubo respuestas, views, entrevistas o silencio.
\item Registrar objeciones y ajustar una pieza.
\item Definir la unica prioridad de la siguiente semana.
\end{enumerate}

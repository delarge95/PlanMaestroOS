\section{Como hablar de dinero}


No abrir con el minimo. El minimo es para decisiones internas, no para anclar negociacion.


Respuesta si preguntan temprano:


\begin{mdcode}
Bloque de codigo: text
I would like to understand scope, responsibilities, contract model and expected time commitment first. Since contractor compensation depends heavily on taxes, benefits, paid time off and contract risk, I prefer to evaluate the full package rather than only a monthly number.
\end{mdcode}


Respuesta si exigen rango:


\begin{mdcode}
Bloque de codigo: text
For aligned remote contractor roles, my realistic target is around USD 2000/month. I can evaluate lower entry offers if the role is strongly aligned with Unity/realtime 3D/technical art and has a clear growth path, and higher ranges depending on scope, responsibility and contract model.
\end{mdcode}

\section{Decision de aceptar}


Aceptar si:


\begin{itemize}
\item Fit tecnico >= 4/5.
\item Aprendizaje transferible claro.
\item Contrato/pago suficientemente claro.
\item Carga horaria deja sostener crecimiento.
\item No contradice reglas legales o claims publicos.
\end{itemize}


Negociar si:


\begin{itemize}
\item El fit es bueno pero el pago bajo.
\item El contrato es bueno pero IP/exclusividad son demasiado amplias.
\item El rol es interesante pero scope ambiguo.
\end{itemize}


Rechazar si:


\begin{itemize}
\item Marketing puro sin 3D/Unity.
\item Prueba larga no pagada.
\item Work authorization imposible.
\item Pago informal o sin contrato.
\item Exclusividad abusiva con paga baja.
\end{itemize}


\section{Plan si aceptas una oferta baja afin}


\begin{enumerate}
\item Definir objetivo de aprendizaje de 90 dias.
\item Mantener portfolio una noche/semana.
\item Documentar logros sin violar NDA.
\item Pedir feedback y revision salarial.
\item No abandonar pipeline externo hasta pasar periodo de prueba.
\end{enumerate}

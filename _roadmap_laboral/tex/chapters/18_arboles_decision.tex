\chapter{Arboles de decision}

\section{Si tengo solo una hora hoy}


\begin{enumerate}
\item Si portfolio no esta listo: mejora TwinSight case.
\item Si portfolio esta listo: envia una aplicacion o follow-up.
\item Si hay entrevista cerca: practica pitch y preguntas dificiles.
\item Si todo esta quieto: actualiza tracker y decide proximo bloqueo.
\end{enumerate}


\section{Si no se que estudiar}


\begin{enumerate}
\item Mira el asset que bloquea empleo.
\item Elige el skill que desbloquea ese asset.
\item Estudia maximo 90 minutos.
\item Aplica inmediatamente lo estudiado.
\item Documenta el output.
\end{enumerate}

\section{Si aparece rol que pide senior}


\begin{itemize}
\item Aplicar solo si el core conecta fuerte con TwinSight.
\item No cambiar titulo propio a Senior.
\item En mensaje decir que el fit esta en Unity/technical visualization/pipeline.
\item Aceptar que puede ser long shot.
\end{itemize}


\section{Si una empresa pide EU/US work authorization}


\begin{itemize}
\item Si lo exige como requisito duro: descartar.
\item Si dice preferred: aplicar con wording Colombia contractor.
\item No usar pasaporte portugues futuro como autorizacion actual.
\item Registrar bloqueo en tracker.
\end{itemize}


\section{Si ARA empieza a distraer}


\begin{enumerate}
\item Preguntar: TwinSight/GitHub/CV/LinkedIn estan listos?
\item Si no: pausar ARA.
\item Si si: hacer sprint ARA de maximo 1 semana.
\item Si ARA no produce demo/README: bajarlo de prioridad.
\end{enumerate}

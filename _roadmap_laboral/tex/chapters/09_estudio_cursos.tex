\subsection{Decision para certificacion Unity}


Tomarla solo si estas condiciones se cumplen:


\begin{itemize}
\item Portfolio y TwinSight estan publicados.
\item GitHub y CV estan listos.
\item Ya hiciste al menos 20 aplicaciones o 2 semanas de soft launch.
\item El examen se puede preparar en 2-4 semanas.
\item No desplaza aplicaciones ni entrevistas.
\end{itemize}


\subsection{Decision para master}


Master solo si mejora al menos 3 de 5:


\begin{itemize}
\item Movilidad/visa.
\item Red laboral.
\item Practicas o industria.
\item Especializacion directa en realtime/XR/technical art/simulation.
\item Costo razonable o beca.
\end{itemize}


PhD queda pausado salvo giro claro a investigacion o beca excelente con objetivo R\&D.

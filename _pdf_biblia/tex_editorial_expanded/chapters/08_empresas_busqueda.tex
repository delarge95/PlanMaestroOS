\subsection{Disqualifiers}


No aplicar si el posting exige:


\begin{itemize}
\item US/EU work authorization required now and no sponsorship.
\item Onsite only in pais inaccesible.
\item AAA senior Technical Artist con 5+ anos shipping experience.
\item Pure full-stack role sin 3D/Unity/WebGL angle.
\item Unpaid test, unpaid trial or upfront payment.
\item Security/export controlled work incompatible with location/status.
\end{itemize}


\subsection{Protocolo de verificacion antes de aplicar}


\begin{enumerate}
\item Guardar URL del rol y fecha.
\item Marcar remote scope: worldwide, LATAM, Colombia, US-only, EU-only, hybrid.
\item Identificar modalidad: employee, EOR, contractor, freelance, unknown.
\item Identificar authorization requirement.
\item Elegir portfolio angle: TwinSight, ARA, Blender, fallback Python.
\item Registrar contacto/recruiter si existe.
\item Decidir Apply / Outreach / Track / Discard.
\end{enumerate}

El portafolio debe convertir una historia academica dispersa en evidencia laboral concentrada. No basta con decir Unity/WebGL: hay que demostrar pipeline, decisiones, interaccion, optimizacion, evaluacion y limitaciones.

\subsection{Reglas de estilo de portfolio}


\begin{itemize}
\item Lead with demo, problem, solution and features; move methodology lower.
\item No usar lenguaje de producto comercial si fue prototipo academico.
\item No ocultar limitaciones; usarlas como senal de criterio tecnico.
\item Cada screenshot debe explicar una decision, no solo verse bonito.
\item Cada proyecto debe tener next steps y productionization plan.
\end{itemize}

\subsection{LinkedIn}


Headline recomendado:


\begin{mdcode}
Bloque de codigo: text
Real-Time 3D Developer / Unity Technical Artist | Unity WebGL, CAD-to-Realtime Optimization, Interactive Technical Visualization
\end{mdcode}


About debe tener cuatro bloques: identidad, TwinSight, skills, disponibilidad. Debe mencionar Colombia remoto contractor/B2B y no afirmar autorizacion UE actual.


Featured order:


\begin{enumerate}
\item TwinSight X500 case study
\item TwinSight 90-second demo
\item GitHub repository
\item ArtStation breakdown
\item ARA Framework only if clean
\end{enumerate}


Skills order:


\begin{itemize}
\item Unity
\item C\#
\item WebGL
\item Technical Art
\item Real-Time 3D
\item Technical Visualization
\item CAD-to-Realtime
\item Blender
\item UI Toolkit
\item Python Automation
\end{itemize}

Primer bullet TwinSight:


\begin{mdcode}
Bloque de codigo: text
Built TwinSight X500, a Unity WebGL technical visualization prototype for drone assembly inspection using Unity, C#, URP, UI Toolkit and Blender.
\end{mdcode}


CV QA:


\begin{itemize}
\item Una pagina ATS-friendly para aplicaciones rapidas.
\item Links vivos a portfolio, GitHub, LinkedIn y demo.
\item TwinSight primero.
\item Metricas solo si estan verificadas contra tesis final.
\item No listar cursos sin certificado como certificaciones.
\item No usar senior como titulo principal.
\end{itemize}


\subsection{GitHub}


Pinned repos:


\begin{enumerate}
\item TwinSight X500 / WebGL-Thesis-Proposal
\item ARA Framework, solo si esta limpio
\item Blender technical art breakdown, si existe como repo o asset page
\item AI News Aggregator, solo si funcional
\item Portfolio website repository
\end{enumerate}


TwinSight README:


\begin{itemize}
\item Overview recruiter-readable.
\item Live demo / video demo.
\item Why this project exists.
\item Core features.
\item Technical architecture.
\item CAD-to-realtime pipeline.
\item Optimization details.
\item Evaluation and metrics.
\item Limitations.
\item Roadmap / production improvements.
\end{itemize}


\subsection{ArtStation / visual breakdown}


ArtStation no debe ser solo beauty shots. Debe mostrar pipeline: cover, video, final screenshots, feature breakdown, CAD optimization, visual modes, tools, metrics and links.

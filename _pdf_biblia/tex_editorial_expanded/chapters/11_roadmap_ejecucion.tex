\subsection{Done definition semanal}


\begin{itemize}
\item 5+ roles scored.
\item 3-8 aplicaciones enviadas segun readiness.
\item Tracker actualizado.
\item Follow-ups enviados cuando corresponda.
\item Un asset mejorado o una objecion convertida en respuesta.
\item Una nota de aprendizaje semanal escrita.
\end{itemize}

\subsection{QA final antes de publicar}


\begin{itemize}
\item Todos los enlaces abren: portfolio, GitHub, LinkedIn, demo, CV.
\item No hay placeholders visibles.
\item La primera pantalla comunica rol y proyecto, no historia personal larga.
\item El caso menciona limitaciones sin debilitar el valor.
\item Las metricas coinciden con tesis/documentos finales.
\item Los repos no tienen secretos, archivos pesados innecesarios ni README vacio.
\item Las imagenes tienen captions tecnicas.
\item La disponibilidad dice Colombia remote contractor/B2B y no EU authorization.
\end{itemize}

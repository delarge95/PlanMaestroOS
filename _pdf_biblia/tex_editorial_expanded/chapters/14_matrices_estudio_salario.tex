\subsection{Red flags de contrato}


\begin{itemize}
\item Prueba tecnica larga no pagada sin alcance ni feedback.
\item Exclusividad amplia para contractor sin compensacion equivalente.
\item IP demasiado amplia que impide mostrar portfolio propio.
\item No hay contrato escrito o el pago queda informal.
\item Piden autorizacion UE/US actual cuando no existe.
\item Scope ambiguo: Unity, backend, design, support y 3D todo por tarifa baja.
\item Pago condicionado a aprobaciones subjetivas sin hitos.
\item No hay fecha de pago, moneda ni responsable de aprobacion.
\end{itemize}


\subsection{Checklist antes de aceptar}


\begin{enumerate}
\item Confirmar rol real, seniority esperado y entregables.
\item Confirmar modalidad: contractor, EOR, employee o freelance project.
\item Convertir oferta a bruto mensual y neto estimado.
\item Valorar tiempo no pagado: vacaciones, sickness, reuniones y onboarding.
\item Revisar IP, NDA, portfolio permission y exclusividad.
\item Comparar contra scorecard de rol, dinero, aprendizaje y riesgo.
\item Negociar si el fit es bueno pero el contrato esta incompleto.
\item No firmar bajo presion sin leer clausulas clave.
\end{enumerate}

# Roadmap Plan Maestro OS — Visión general y prioridades

## Visión
Plan Maestro OS es un **segundo cerebro operativo** centrado en ejecución diaria, salud, carrera y aprendizaje. No es un simple dashboard: es un sistema que:

- Organiza y prioriza tareas (Hoy).
- Integra fitness, clínica, trabajo, idiomas y gastronomía.
- Usa IA y automatización para reducir fricción, no para reemplazar decisiones.
- Respeta TDAH, ansiedad social y fatiga: minimalismo, foco, baja carga cognitiva.

## Prioridades MVP
1. **Hoy / Live tracker** (tareas, calendario, foco).
2. **Fitness** (rutinas, progreso, habilidades, prehab).
3. **Laboral** (roadmap, portafolio, empleo, proyectos).
4. **Idiomas** (Alemán primero, Inglés después).
5. **Clínico** (TDAH, ansiedad social, regulación).
6. **Gastronomía** (MVP de biblioteca y planes).

## Fases generales
- Fase 0: Setup técnico base.
- Fase 1: Hoy + Agenda + Fitness básico.
- Fase 2: Fitness completo.
- Fase 3: Clínico.
- Fase 4: Laboral.
- Fase 5: Idiomas.
- Fase 6: Gastronomía.
- Fase 7: IA, RAGs y automatizaciones avanzadas.

## Dependencias clave
- Notion como fuente operativa.
- GitHub como fuente de código y proyectos.
- FitApp como motor de fitness.
- Astro como shell.
- Worker para sync, IA y jobs.

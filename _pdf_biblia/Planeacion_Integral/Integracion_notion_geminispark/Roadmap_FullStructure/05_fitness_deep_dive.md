# Fitness: diseño profundo

## Modelo de datos
- TrainingProgram, ProgramWeek, WorkoutDay, ExercisePrescription.
- SkillPath, SkillStep.
- WorkoutSession, SetLog, PersonalRecord.
- BodyMetric, PrehabProtocol, MobilityRoutine.

## Vistas
- Hoy (fitness).
- Calendario fitness.
- Catálogo de rutinas.
- Habilidades y progresiones.
- Base de datos y biblioteca.
- Progreso y tabla de cargas.

## Reglas UX
- Máximo 3 tipos de información por vista.
- Gráficas avanzadas detrás de botón.
- Prehab visible solo si aplica.

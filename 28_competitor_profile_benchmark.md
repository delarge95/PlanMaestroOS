# 28_competitor_profile_benchmark

## Scope

This module integrates the result of:

```text
A1_linkedin_profiles_benchmark
```

The source data was collected from publicly visible search snippets and LinkedIn-result metadata. LinkedIn profile pages were not fully accessible without login, so this benchmark must be treated as a **surface-level positioning benchmark**, not as a complete profile audit.

## Data limitations

| Limitation | Impact |
|---|---|
| LinkedIn profile pages restricted | About, full experience, education and featured projects are often unavailable |
| Search snippets only | Data is incomplete and may omit important context |
| Most portfolio links not visible | Cannot judge project quality directly |
| Seniority often inferred from title | Confidence varies |
| Remote/contractor status rarely visible | Must not assume remote eligibility |
| Search result snippets may change | Recheck important profiles manually before copying patterns |

## Correct use

Use this module to extract:

- headline patterns;
- role title patterns;
- market vocabulary;
- seniority patterns;
- niche clusters;
- signals to copy carefully;
- signals to avoid;
- profile gaps in Alexander’s current positioning.

Do **not** use it to claim direct equivalence with senior profiles.

# 1. Executive findings

## Main finding

The public profile landscape confirms that Alexander’s positioning is coherent if expressed as:

```text
Real-Time 3D Developer / Unity Technical Artist
```

with strong supporting keywords:

```text
Unity · C# · Unity WebGL · Technical Visualization · CAD-to-Realtime · Blender · Interactive 3D · Simulation · XR · Digital Twin
```

The strongest comparable profiles tend to cluster around one of five families:

1. **Unity Technical Artist**
2. **Real-Time 3D / Interactive 3D Developer**
3. **Unity WebGL Developer**
4. **XR / Simulation / Digital Twin Developer**
5. **Unity Tools / Pipeline Developer**

```text

Unity + Tools

```

TwinSight gives a stronger niche than generic gameplay.

# 12. Gaps revealed by benchmark

## Gap 1 — Public portfolio links

Most comparable profiles likely have visible projects, but the search snippets did not expose them.

Alexander needs direct visible links:

- portfolio;
- TwinSight demo;
- GitHub;
- ArtStation if used.

## Gap 2 — Industry wording

The market uses short titles. Avoid academic phrasing.

Use:

```text
Unity WebGL technical visualization prototype
```

instead of:

```text
Design Science Research artifact for cognitive support in drone assembly documentation
```

Use the academic framing deeper in the case study, not in the headline.

## Gap 3 — Specialized proof

For Technical Artist roles, current proof is strongest in:

- optimization;
- pipeline;
- visual modes;
- Unity runtime;
- UI;
- technical visualization.

It is weaker in:

- advanced shaders;
- Houdini;
- VFX;
- shipped game pipelines;
- studio production tools.

## Gap 4 — XR

XR appears frequently in comparable profiles. Alexander can target XR-adjacent roles, but should add one small XR or spatial-interaction artifact if XR becomes a serious target.

## Gap 5 — Digital twin

Digital twin appears as a strong adjacent market. Alexander can use TwinSight as a **digital-twin-adjacent technical visualization** project, but should not claim production digital twin experience.

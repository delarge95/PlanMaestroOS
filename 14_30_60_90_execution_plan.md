# 14_30_60_90_execution_plan

## Purpose

This section converts the prior strategy files into a 90-day execution system.

It is not a market research document. It is an operating plan for moving from thesis completion and portfolio preparation into structured international applications, interviews, negotiation, and offer evaluation.

## Baseline assumptions

| Item | Current state |
|---|---|
| Location | Colombia |
| Time zone | America/Bogota |
| Thesis | Complete |
| Thesis status | Pending defense |
| Primary asset | TwinSight X500 |
| Main target | Remote international work |
| Preferred model | Contractor / B2B |
| Minimum target | USD 1.5k/month |
| 6-month target | USD 3k/month |
| 12–24 month target | USD 6k/month |
| EU status now | No current EU work authorization |
| EU future | Portuguese passport expected |
| Germany route | Possible via marriage/residence |
| Primary roles | Real-Time 3D / Unity / Technical Visualization |
| Secondary roles | Tools / Python automation |
| Main risk | Strategic dispersion |

## Operating principle

The plan prioritizes **visible proof of skill** over additional passive learning.

The critical path is:

```text
TwinSight proof → portfolio MVP → LinkedIn/CV/GitHub alignment → targeted applications → interviews → offer evaluation
```

The plan should not be interrupted by:

- starting a new major project;
- rewriting the thesis unnecessarily;
- taking long courses without output;
- polishing low-relevance repositories;
- targeting unrelated full-stack jobs too early;
- waiting for Portuguese citizenship before applying;
- treating Germany as the immediate employment base.

## 90-day outcome targets

By the end of 90 days, the expected state should be:

1. A public-facing portfolio MVP exists.
2. TwinSight X500 has a recruiter-ready case study.
3. GitHub no longer looks unfocused.
4. LinkedIn and CV match the same positioning.
5. At least 120 companies have been classified.
6. At least 80–150 targeted applications or outreach actions have been made.
7. At least 8–15 recruiter or hiring-manager conversations have been attempted.
8. At least 3–6 interview processes have been initiated.
9. Offer evaluation criteria are operational.
10. A 12-month skill roadmap is active.

These targets are not guarantees. They are execution metrics.

# 4. Phase 3 — Days 61–90

## Objective

Scale what works, reject weak paths, and convert interviews into offers.

## Week 10: target refinement

### Segment all companies into

| Segment | Meaning |
|---|---|
| A1 | High fit, active hiring |
| A2 | High fit, no active role |
| B1 | Good fit, realistic |
| B2 | Good fit, weak signal |
| C | Fallback |
| Reject | Distraction |

### Actions

- Stop applying to weak C targets unless cashflow requires it.
- Increase outreach to A1/A2.
- Use speculative outreach for high-fit studios.
- Reuse TwinSight in technical messages.
- Ask for referrals where possible.

## Week 11: interview conversion

### Tasks

- Prepare per-company notes.
- Build role-specific TwinSight explanation.
- Prepare 5 technical stories.
- Prepare whiteboard/system design answers.
- Prepare code walkthrough.
- Prepare negotiation stance.

### Technical stories to prepare

| Story | Evidence |
|---|---|
| CAD optimization | Triangle reduction |
| Web deployment | WebGL constraints |
| Interaction system | Selection/exploded/cut |
| UI system | UI Toolkit |
| Validation | SUS / NASA-TLX |
| AI assistance | Judgment/debugging |
| Limitation | Honest tradeoffs |

## Week 12: offer and pipeline management

### Offer evaluation model

Score each offer from 1–5:

| Criterion | Weight |
|---|---:|
| Gross compensation | 20 |
| Net compensation | 15 |
| Role fit | 20 |
| Portfolio leverage | 15 |
| Contract safety | 10 |
| Remote stability | 10 |
| Learning ROI | 5 |
| EU leverage | 5 |

Reject or renegotiate if:

- total score is low;
- payment terms are vague;
- unpaid trial is large;
- exclusivity is broad;
- IP terms are abusive;
- salary is below minimum;
- role dilutes the portfolio.

## Week 13: strategic decision point

At day 90, decide between four paths:

| Path | Trigger |
|---|---|
| Continue same strategy | Interviews active |
| Increase volume | Replies low |
| Improve portfolio | Technical rejection |
| Add fallback roles | Cashflow pressure |
| Pause for skill sprint | Repeated test failures |

### Day 90 review questions

1. Which role family generated the most replies?
2. Which portfolio asset got technical attention?
3. Which job boards produced interviews?
4. Which companies ignored the profile?
5. Which salary ranges were accepted?
6. Which questions caused weak answers?
7. Which technical tests failed?
8. Is ARA helping or distracting?
9. Is the portfolio sufficient?
10. Is cashflow becoming urgent?

# 11. Decision gates

## Gate 1 — Day 30

Proceed to scaled applications only if:

- CV ready;
- LinkedIn updated;
- TwinSight visible;
- GitHub acceptable;
- portfolio MVP live or shareable;
- tracker active.

If not, extend Phase 1 by one week.

## Gate 2 — Day 60

Continue current strategy only if:

- replies exist;
- interviews exist or seem close;
- portfolio feedback is not negative;
- target roles still fit.

If not, adjust:

| Failure | Adjustment |
|---|---|
| No replies | Rewrite positioning |
| Wrong replies | Change target list |
| Low offers | Raise company tier |
| Technical failures | Skill sprint |
| Portfolio confusion | Simplify projects |

## Gate 3 — Day 90

Decide:

```text
Continue / Pivot / Add fallback / Skill sprint / Accept offer
```

The decision must be based on tracker evidence, not mood.

# 14. Final 90-day operating statement

The operational target for the next 90 days is:

```text
Use TwinSight X500 as the proof asset to enter real-time 3D, Unity WebGL, technical visualization, digital twin, simulation, and Unity Technical Artist conversations, while using ARA and Python tooling only as secondary evidence of automation capability.
```

The first offer does not need to be perfect. It must satisfy:

1. compensation above the minimum threshold;
2. role fit with the portfolio direction;
3. acceptable contract risk;
4. remote feasibility from Colombia;
5. ability to build toward USD 3k–6k/month over 12–24 months.

If an offer fails these criteria, it is not automatically a strategic win even if it is international.

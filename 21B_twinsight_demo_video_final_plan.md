# 1. Objective

Produce a polished video system for **TwinSight X500**, the flagship portfolio project.

The video system must prove, in the shortest possible time, that Alexander can operate as:

```text
Real-Time 3D Developer / Unity Technical Artist
Unity WebGL · C# · CAD-to-Realtime · Technical Visualization · Interactive 3D
```

The video must not be a generic thesis presentation. It must be a recruiter-readable and technical-lead-readable demonstration of:

- final product quality;
- Unity WebGL implementation;
- runtime interaction;
- technical UI;
- CAD-to-realtime optimization;
- real-time visualization modes;
- evaluation evidence;
- clarity of role and contribution.

---

# 2. Strategic reason

The market evidence from B1 and B5 reinforces that video proof is not optional.

Relevant hiring signals found:

| Market signal | Implication for video |
|---|---|
| Unity / C# appears repeatedly | show Unity + C# clearly |
| Technical Art roles request pipeline and optimization | show visual modes and CAD optimization |
| Render / Graphic Programmer roles value shaders, math, GPU and performance | include visual mode and optimization evidence |
| VR / XR Unity roles value interaction and profiling | show runtime interaction and future XR-adjacent logic |
| LATAM remote roles ask for portfolio evidence | video must be portfolio-ready |
| Freelance/talent-pool roles ask for strong portfolio | video must be self-contained proof |
| Blender appears in some Unity/VR postings | show Blender pipeline briefly |
| Web platform appears in LATAM freelance roles | show browser/WebGL proof |

Conclusion:

```text
The video must show both product value and technical implementation.
```

# 20. Risk controls

## 20.1 Overclaim risks

| Risk | Control |
|---|---|
| calling it a full digital twin | say digital-twin-adjacent |
| implying production deployment | say prototype |
| implying IoT | state no live IoT |
| implying physical simulation | thermal-style is visual only |
| hiding AI assistance | disclose if relevant |
| overclaiming seniority | focus on project evidence |
| overclaiming XR | say future extension unless implemented |

## 20.2 Exact safe wording

```text
academic/portfolio prototype
formative evaluation
technical visualization
digital-twin-adjacent
browser-based viewer
qualitative thermal-style visual mode
CAD-derived assets
optimized for WebGL
```

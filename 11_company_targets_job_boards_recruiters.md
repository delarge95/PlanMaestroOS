## Data quality rules

The previous agent result was useful but incomplete. It collected some strong targets and job boards, but it did not verify 120 companies one by one. This final version therefore uses three verification labels:

- **Verified:** official website/careers page or direct evidence checked.
- **Partial:** official website known, but current openings/remote rules not checked.
- **Watchlist:** plausible fit, but must be verified before application.

Remote labels are conservative. **Remote does not mean worldwide** unless the company states it.

## Current operational interpretation

Use this file as an ecosystem map, not as a direct application list.

- The company identity table is the broad universe of possible targets.
- The hiring feasibility table is a working hypothesis about role fit, remote posture, and authorization friction.
- The scoring table is a prioritization seed, not proof that a company has a current opening.
- A target only becomes application-ready after a current opening, remote scope, contractor/payroll route, and work authorization requirements are checked.

Historic notes should not override current profile data. If a newer non-historic file conflicts with older historic context, use the newer non-historic data.

Operational layers override the broad A/B/C label when planning weekly execution:

| Layer | Use | Action |
|---|---|---|

### Application disqualifiers

Do not apply until resolved when a posting has any of these flags:

- Requires current US/EU/UK work authorization and has no contractor/B2B path.
- Requires security clearance.
- Requires shipped AAA titles or senior commercial game credits as a hard requirement.
- Is a pure art production role with no technical systems, tooling, scripting, optimization, or interactive component.
- Is local Germany/Portugal payroll-only before the relevant residence/work authorization path is active.
- Has no credible bridge to TwinSight, Unity WebGL, CAD-to-realtime optimization, simulation, XR, technical art, Python automation, or ARA.
